# Sepsis_Onset_Prediction
Predicts sepsis onset 6 hours ahead from ICU time-series data (PhysioNet Sepsis Challenge 2019). Handles high-missingness data, mitigates noisy physician-recorded labels via downweighting, prevents temporal and patient-level leakage, and applies probability calibration with recall-oriented threshold selection. XGBoost, Colab-ready notebook.
